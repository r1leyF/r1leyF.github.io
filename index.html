The Enigma Machine?The Enigma machine was a cipher device used to encrypt text.
It was used extensively by Nazi Germany before and during WW2.


Plugs?The plug board swaps pairs of letters.
The plug board is the first thing input text passes through.
It passes through the plug board again after going through the rotors as a last step before the final output.

Rotors?The rotors are a set of 3 rotating disks that scramble letters.
For each letter inputted one or more rotors are turned. This means every letter inputted is encrypted differently.
The starting position of these rotors can be set. Positions are shown with an alphabet ring from A to Z
